Checklist

Collect the useful details first.

1.
Write the exact URL or screen.

Include the page, admin area, product, form, dashboard, or component where the bug appears.

2.
Describe what happens now.

Use observable language: button does nothing, menu overlaps, form sends empty fields, upload fails, page scrolls sideways.

3.
Describe the expected result.

State what should happen after the fix, not just what is broken.

4.
Add reproduction steps.

List the fewest clicks or inputs needed to trigger the issue.

5.
Share safe evidence.

Screenshots, browser name, device size, console error, and redacted test data are useful. Avoid passwords, customer data, private API keys, and payment details.

6.
Name the stack or platform.

Examples: WordPress, Shopify, Webflow, React, Next.js, plain HTML/CSS/JS, PHP, Google Sheets, Formspree, Zapier, n8n.
